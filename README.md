# Manoj Le — Personal Portfolio Website

A modern, responsive, recruiter-friendly personal portfolio website built with **React.js, Vite, Framer Motion, and CSS**.

## 🚀 Features

- **Dark & Light Mode**: Seamless theme switching with persistent preferences.
- **Hero Terminal Card**: Interactive code interface showcasing developer background.
- **Categorized Technical Skills**: Python, C, Data Structures & Algorithms, Data Science, and Machine Learning.
- **Currently Learning Roadmap**: Live tracker for DSA practice, competitive programming, and open-source contributions.
- **Featured Projects Showcase**:
  - `DSA-in-Python`: Data structures and algorithms implementations with complexity analysis.
  - `C-Basics-Projects`: C language fundamentals, pointers, dynamic memory, and file I/O.
  - `Mini-ML-Project`: Data cleaning, feature engineering, and model training workflow.
- **Education Timeline**: B.Tech in Artificial Intelligence & Data Science at Reva University, Bengaluru.
- **Direct Contact & Resume Access**: Fast email dispatch and downloadable resume.

## 🛠️ Tech Stack

- **Framework**: React.js + Vite
- **Styling**: Modern CSS Architecture + CSS Custom Properties
- **Animations**: Framer Motion
- **Icons**: Lucide React + React Icons

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Manoj-LE/portfolio.git

# Navigate into the project
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [My Portfolio](https://portfolio-1d4q.vercel.app/) in your browser.
